# Technical Strategy

**Challenge**: Hypothesis is weakly supported & difficult to comprehensively test
**Approach**: Iterative, freemium SaaS with 100-500 MAU to prove concept and explore product-market fit
<div class="columns">
<div>

<!-- _class: cool-list -->
- **In development**
  - Minimal open source platform (<$0.20/user-mo)
  - Frictionless, free onboarding
  - Predictable user-extensible data model
  - Robust export (pdf, docx)
  - Broad document support (Quill, LaTeX, UML, Markedjs)

</div>  
<div>    

- **Future**
  - Alternative renderers
  - Unstructured views
  - Reporting API
  - Ingest API
  - AI-driven authoring
  - Cross-structure graph visualization

</div>
